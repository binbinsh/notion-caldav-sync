# Security Policy

## Supported version

Security fixes are applied to the latest commit on the `main` branch and the production service at `calendar.planner.li`.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub private vulnerability reporting](https://github.com/binbinsh/notion-caldav-sync/security/advisories/new).

Include the affected endpoint or component, reproduction steps, expected impact, and any suggested mitigation. Do not include real Apple app passwords, Notion tokens, Clerk sessions, Cloudflare credentials, or webhook secrets. Please allow reasonable time for investigation and a coordinated fix before public disclosure.

Public GitHub issues are appropriate for non-sensitive bugs only.
